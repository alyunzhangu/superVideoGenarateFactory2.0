# 产品体验视频故事板生成提示词（自然短片版）

> 适用场景：根据已有 `@分镜脚本`，结合 `@产品参考图 / 产品资料` 与可选的 `@人物参考图`，生成一套自然、真实、不像硬广的产品体验视频故事板提示词。  
> 默认适配：抖音 / 快手 / 小红书 / 视频号 / TikTok 等竖屏带货短视频。  
> 核心目标：让画面像一段有生活气息的短片，产品自然出现，使用过程清楚，体验变化可信，结尾干净克制。  
> 使用方式：将下方「完整提示词」复制到生成工具中，并替换 `【】` 内的信息。

---

## 一、输入素材占位

请在使用前补充以下信息：

- `@分镜脚本`：必须提供。作为故事板的唯一剧情、镜头顺序、动作节奏和内容来源。
- `@产品参考图 / 产品资料`：建议提供。包括产品外观、包装、颜色、材质、使用方法、细节特征、适用场景和真实体验点。
- `@人物参考图`：可有可无。若提供，则严格作为出镜人物 / 使用者的形象参考；若未提供，则根据分镜脚本生成自然人物、手部演示、局部人物或纯产品画面。
- `@视觉氛围参考`：可选。包括光线、场景、色调、生活方式、镜头质感、画面情绪。
- `视频规格`：默认 `9:16 竖屏，15-60秒，自然生活短视频节奏`。

## 二、完整提示词

使用 `@分镜脚本` 作为产品体验视频故事板的完整叙事、构图、动作、情绪和镜头节奏来源。  
`@产品参考图 / 产品资料` 作为产品外观、包装、材质、颜色、使用方式和细节特征来源。  
`@人物参考图` 为可选人物参考；如果提供人物参考，必须保持人物身份、脸型、发型、妆容、服装、体型比例和气质一致；如果没有人物参考，不要强行生成固定人物，可使用手部演示、局部人物、生活场景人物或纯产品镜头。

请根据 `@分镜脚本` 生成一套完整的产品体验视频故事板。  
故事板必须严格按照脚本中的分镜顺序生成：`Cut 1 → Cut 2 → Cut 3 → Cut 4 → ...`。  
不要重新设计剧情。  
不要改变镜头顺序。  
不要改变产品品类。  
不要改变产品出现与使用的逻辑。  
不要擅自新增无关角色、无关场景或无关道具。  
不要把口播、字幕、标题、分镜说明、脚本备注直接生成到画面主体里。  
故事板图片用于确认人物、产品、场景、构图、动作与镜头节奏，不承担完整脚本传输。不要依赖故事板图片中的文字作为后续 Seedance 指令；完整分镜脚本会在提交 Seedance 时作为独立文本再次传入。
最终画面必须是干净、真实、自然、可用于视频制作参考的故事板画面。

## 四、产品要求

产品必须严格保持 `@产品参考图 / 产品资料` 中的真实外观：

- 保持相同品类、形状、包装结构、瓶身 / 盒身比例、颜色、材质、光泽和主要视觉特征。
- 产品在所有分镜中保持一致，不要一会儿变成瓶装、一会儿变成盒装、一会儿变成其他品类。
- 如果产品有包装、瓶身、喷头、盖子、刷头、屏幕、按键、纹理、食物形态、液体质地等关键细节，必须在近景或特写镜头中清楚呈现。
- 产品必须自然地存在于场景中，可以被拿起、打开、使用、放回、靠近镜头展示，但不要像漂浮物或过度摆拍。
- 产品比例必须自然可信，不要过大、过小、漂浮、变形、缺失部件或出现多个错误版本。
- 如果参考图中有品牌 LOGO 或包装文字，尽量保持位置和视觉结构；如果无法准确生成文字，不要生成乱码、伪中文、错误英文或虚假品牌字样，可保持包装干净或用抽象色块替代文字区域。

不要改变产品品类。  
不要改变产品包装。  
不要改变产品颜色。  
不要生成无关产品。  
不要生成无关道具抢占主体。  
不要让产品变形、融化、破损、脏污或比例异常，除非分镜脚本明确要求。

## 五、人物要求（可选）

如果提供 `@人物参考图`：

- 出镜人物 / 使用者必须严格保持参考图中的人物形象。
- 保持相同脸型、五官、发型、发色、妆容、服装风格、身材比例和整体气质。
- 不要变脸。不要换人。不要换服装风格。不要突然改变年龄、性别、体型或气质。
- 人物表情应自然、松弛、可信，符合真实生活状态，不要夸张表演。
- 人物动作必须服务于产品使用，不要让人物抢走产品主体。

如果没有提供 `@人物参考图`：

- 根据分镜脚本决定是否出现人物。
- 可以使用手部演示、半身使用者、生活场景人物、背影、局部肢体或纯产品镜头。
- 不要凭空创造夸张明星脸、网红脸、二次元人物、漫画人物或与产品无关的角色。
- 若脚本强调真实使用，人物应自然生活化；若脚本强调质感氛围，人物应干净、简洁、不过度表演。

人物面部必须干净、自然、清晰、可信。  
人物手部必须自然、干净、比例正确，适合产品演示。

不要脸部灰脏。  
不要黑斑。  
不要灰斑。  
不要脏妆。  
不要烟熏妆。  
不要黑眼圈。  
不要皮肤塑料感。  
不要五官扭曲。  
不要手指畸形。  
不要多手指。  
不要缺手指。  
不要手部穿模。  
不要产品与手部粘连。  
不要让头发、手、道具遮挡产品关键细节。

## 七、场景要求

场景必须来自 `@分镜脚本`，并服务于产品的真实使用方式。  
严格按照脚本中描述的环境生成，不要随意切换到无关场景。

常见自然场景可包括：

- 家居：客厅、卧室、厨房、浴室、阳台、收纳空间。
- 洗护个护：浴室镜前、洗手台、梳妆台、晨间 / 夜间护理场景。
- 食品饮品：厨房、餐桌、办公室、户外轻食、运动后休息场景。
- 服饰鞋包：玄关、衣柜前、通勤路上、室内搭配、自然街景。
- 数码家电：办公桌、客厅、卧室、桌面整理、真实使用环境。
- 母婴宠物：温暖家居、亲子互动、宠物活动区，画面安全、柔和、真实。

所有分镜必须处于同一条连续叙事中。  
如果是连续动作，场景、人物、产品位置和光线要保持连续。  
如果是多场景内容，转场必须自然，不能像随机拼接图片。

不要突然切换到完全无关的城市、森林、沙漠、室内、室外等环境。  
不要出现脏乱背景。  
不要出现与产品气质冲突的环境。  
不要让背景比产品更抢眼。

## 八、分镜结构要求

请严格按照 `@分镜脚本` 中的每一个镜头生成故事板。  
如果脚本中没有明确时间轴，请根据总时长自动拆分为合理节奏。  
默认产品体验视频节奏如下，但必须以脚本为准：

1. **生活情境引入**：从一个真实场景、细微需求或使用前状态开始，不要过度戏剧化。
2. **产品自然出现**：产品以合理方式进入画面，例如放在桌面、从包里拿出、从架子上取下、打开包装。
3. **使用过程展示**：呈现拿起、打开、涂抹、清洁、安装、收纳、饮用、穿戴、按键、倒出等动作。
4. **细节近景**：展示材质、质地、结构、容量、纹理、光泽、声音、手感或变化过程。
5. **使用后状态**：呈现空间更整洁、人物更放松、物品更好用、画面更清爽等自然结果。
6. **安静收束**：保留一个干净的产品画面或使用后的场景余韵，不要做强烈喊卖感。

每个分镜都必须明确：

- 镜头编号：Cut 1、Cut 2、Cut 3……
- 时间范围：如 `0.0s - 3.0s`。
- 景别：大全景、全景、中景、近景、特写、微距特写、俯拍、手持跟拍等。
- 镜头运动：推近、拉远、横移、跟拍、俯拍、轻微旋转、定格观察等。
- 人物动作：拿起、打开、试用、闻、吃、涂抹、清洁、安装、收纳、开箱等。
- 产品呈现：产品在画面中的位置、大小、角度、与手部 / 人物 / 场景的关系。
- 体验重点：该镜头要表达的使用方式、细节质感、便利性、变化过程或使用后的状态。
- 情绪氛围：轻松、可信、安静、治愈、清爽、细腻、真实、有生活感等。
- 字幕 / 口播位置：只作为画面外说明或安全区规划，不要把大段文字生成在画面主体里。

## 九、口播与字幕要求

口播、字幕和说明文案可以作为故事板说明输出，但不要直接生成进画面主体。  
画面中如需预留字幕区域，底部保留约 10%-15% 的干净安全区。  
字幕区不能遮挡人物脸部、手部操作、产品包装、使用过程和关键细节。

口播应像自然分享，而不是强推：

- 开头从真实情境或使用感受进入，不要夸张喊口号。
- 每个镜头只表达一个清楚的信息。
- 少用绝对化形容，优先描述画面里能看到的变化。
- 不要夸大效果，不要虚假承诺。
- 涉及食品、健康、美妆、母婴、金融等敏感品类时，只能表达真实体验、使用感、外观、便利性或合规信息，不要生成治疗、治愈、永久有效、百分百保证等绝对化说法。

## 十、画面风格

整体风格：真实、干净、清晰、自然、有生活气息。  
默认竖屏 `9:16`，适合手机端观看。  
画面应像一段自然记录下来的生活短片：开头有情境，中段有使用过程，结尾有安静的产品或场景余韵。

可根据产品气质选择以下风格：

- 生活实拍感：真实家居 / 办公 / 户外环境，可信、自然、有代入感。
- 干净质感：简洁背景、柔和布光、细腻反光、产品材质清楚。
- 轻测评感：桌面演示、真实操作、前后状态对比、自然口播氛围。
- 情绪短片感：柔和光影、浅景深、慢动作、氛围感强，适合美妆、香氛、服饰、生活方式产品。
- 清晰演示感：光线明亮、镜头稳定、步骤清楚，适合家电、工具、清洁、数码产品。

画面必须清楚展示产品。  
产品必须有真实材质和合理光影。  
人物、手部、场景、道具都必须服务于产品使用。  
不要让画面像促销海报、硬广大片、夸张直播间、普通写真、旅游片或纯情绪短片。

---

## 十一、镜头节奏

必须表现完整的自然体验节奏：  
`生活情境 → 产品自然出现 → 使用过程 → 细节近景 → 使用后状态 → 安静收束`。

如果 `@分镜脚本` 已经给出明确节奏，必须严格跟随脚本。  
不要让每段像无关画面。  
不要让产品只在结尾突然出现。  
不要只有人物表演而没有产品使用。  
不要只有产品静物而没有使用逻辑。  
不要跳过关键使用过程。  
不要突然改变场景、人物、产品包装或光线风格。

---

## 十二、声音与动效说明

故事板中可以规划声音，但不要把声音内容画进画面。

可规划的声音包括：

- 真实环境声：厨房水声、开箱声、喷雾声、按键声、风声、脚步声、包装摩擦声。
- 产品使用声：清洁摩擦声、液体倒出声、喷头按压声、食物咀嚼声、机器运转声、布料摩擦声。
- 轻微情绪音效：自然转场、细节出现、使用前后状态变化时的轻提示音。
- 口播：围绕每个分镜的真实体验，短句、自然、克制。

如果需要音乐，风格应符合产品气质。  
不要让音乐、音效或口播描述影响画面准确性。

---

## 十三、16:9 导演预制作故事板版式（强制）

最终给 image2 生成的故事板图片，不是竖屏视频截图拼图，而是一张横版 `16:9` 的电影制作板 / 视觉规划表。它应该像导演的预制作指南，能一眼传达短片的基调、人物、产品、空间、动线、镜头节奏和声音方向。

画面整体要求：

- 创建一张专业、电影化、设计感清晰的 `16:9` 横版故事板总览图。
- 版面基于网格，信息分区明确，既包含参考信息，也包含分镜推进。
- 画面应像广告导演、摄影指导、造型师、剪辑师都能共用的 pre-production board。
- 不要只生成九宫格分镜，不要只生成竖屏短视频截图拼图。
- 所有分镜内容仍必须来自 `@分镜脚本`，不得改剧情、换顺序或新增无关镜头。

必须包含以下清晰标记的部分：

1. **共享创意指导（顶部栏）**
   - 写明镜头数量、视频比例、统一调色板、主要场景、整体拍摄手法。
   - 用简短视觉标签表达：UGC 手机感 / 自然光 / 暖棕米白 / 真实带货体验 / 生活化节奏。

2. **角色与风格参考**
   - 当提供 `@人物参考图` 时，必须把人物参考图转化为视觉规划区，而不是只在分镜中偶尔出现人物。
   - 必须出现 **人物多角度** 展示：正面、侧面、背面或半侧面、自然放松姿态。
   - 必须出现 **人物细节特写**：脸部/眼部、头发或头巾、手部、服装材质、关键配饰。
   - 强调身份一致性：脸型、五官、发型/头巾、妆容、服装、体型比例和气质保持一致；允许在具体镜头里有自然姿势变化。

3. **产品参考区**
   - 清晰展示产品正面、材质纹理、logo/品牌区域、开口/内部结构、手柄或关键部件。
   - 产品必须严格来自 `@产品参考图 / 产品资料`，保持品类、形状、颜色、材质、比例和关键图案。
   - 如果产品参考图里有文字或 logo，优先保留视觉位置和结构；无法准确生成文字时不要生成乱码。

4. **环境和场景设计**
   - 展示主要室内/户外环境氛围参考。
   - 必须包含一个 **俯视动线示意图**：说明人物、产品、桌面/街道/镜子等空间关系。
   - 在动线图上标注摄像机位置、人物移动方向、产品出现位置和主要拍摄类型。

5. **故事板分镜区**
   - 展示约 8-9 个编号分镜，严格对应 `@分镜脚本`。
   - 每个分镜需要体现：摄像机类型 / 镜头感觉、景别（广角、中景、特写、微距）、运动方式（静态、跟踪、手持、推近、俯拍等）、动作和情绪进展。
   - 每格之间必须有明显差异，避免场景过于相似。
   - **分镜图只保留重要事项**：`Cut 编号 + 时间范围 + 一个关键动作 + 一个必要约束`，例如 `Cut 4 / 3.1-4.0s / 包身纹理微距 / logo 与针织纹理不变形`。
   - 重要事项使用短标签，每条尽量不超过 12 个汉字；不要在故事板图片中排版完整分镜脚本、长段口播内容或密集备注。
   - 不要依赖故事板图片中的文字向 Seedance 传递剧情。完整分镜脚本、口播和备注必须在 Seedance prompt 中以文本形式逐 Cut 重复。
   - image2 无法稳定生成的小字号中文应留空，保留干净的说明条；需要显示的短标签在出图后使用确定性字体排版补充。不得保留乱码、伪中文、扭曲字形或猜测性文字。

6. **灯光/情绪/风格备注**
   - 用小图或色块展示光线条件、时间感、纹理质感和情绪变化。
   - 包括自然室内光、街拍自然光、产品细节光、镜前展示光等过渡。

7. **情绪和关键词块**
   - 用简洁关键词列出作品基调，例如：真实、温暖、轻松、通勤、收纳清晰、材质细节、自然分享。

8. **音频/音调部分**
   - 标明环境声、产品动作声、口播语气和是否有音乐。
   - 默认不添加背景音乐，除非用户明确要求。
