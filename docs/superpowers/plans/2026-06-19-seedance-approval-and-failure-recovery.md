# Seedance Approval and Failure Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Require approval of the exact Seedance prompt/request before every new paid task and turn known provider errors into clear, safe recovery actions.

**Architecture:** `seedance_submit.py` computes a deterministic SHA-256 digest for the final payload, writes an approval preview during dry-run, and rejects new submissions without a matching approved digest. The same module classifies provider failures into immutable structured reports, while `SKILL.md` and prompt references define the user-facing gates and creative recovery loop for both routes.

**Tech Stack:** Python 3 standard library (`hashlib`, `hmac`, `dataclasses`, `json`), Codex Skill Markdown, `unittest`.
